# Sealed brand kit v1.0

Start with `Sealed-Brand-Guidelines.pdf`.

| Folder | What's in it |
|---|---|
| `logos/svg` | Master logos: horizontal, stacked, mark and wordmark in primary, reverse, seal, mono-night and mono-white |
| `logos/png` | Transparent PNGs at 800, 1600 and 3200 wide (mark at 256 to 2048) |
| `logos/jpg` | Logos on white or Night, with clear space built in |
| `app-icons` | iOS and Android sizes in Night, Seal and Paper, plus SVG masters and a maskable icon |
| `favicons` | favicon.ico, favicon.svg (switches in dark mode), PNGs, apple-touch-icon, web manifest |
| `social` | Link preview 1200×630, X header 1500×500, avatars |
| `ui-icons` | 14 line icons on a 24px grid, `currentColor` |
| `fonts` | Young Serif and Public Sans (SIL Open Font License) |
| `tokens` | Colour, type and shape tokens as CSS and JSON |

When in doubt: horizontal, primary, SVG. The name is Sealed, one word, capital S.
